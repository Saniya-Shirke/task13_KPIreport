# task13_KPIreport

## Objective
To build an executive-ready BI dashboard using the Global Superstore dataset and present key performance indicators with actionable insights.

## Tools Used
- Power BI Desktop
- Global Superstore Dataset

## KPIs Created
- Total Sales
- Total Profit
- Profit Margin

## Visualizations Included
- Sales Trend Over Time (Line Chart)
- Sales by Category (Clustered Bar Chart)
- Region Performance (Bar Chart)
- Top 10 Products by Sales (Table)
- Interactive Slicers (Region, Category, Order Date)

## Key Business Insights
1. Technology category generates the highest revenue.
2. West region contributes the maximum sales.
3. Overall profit margin remains stable around 11–12%.
